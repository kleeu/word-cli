# Word CLI (Demo)

一个基于 Python 的命令行背单词工具 Demo，实现了日常新词与复习流程、等级制记忆算法以及撤销、导出等功能。

## 主要特性

- **配置驱动**：使用 `data/config.json` 控制每日新词/复习上限、导出路径等，可在主菜单中动态修改。
- **本地存档**：`data/progress.json` 保持单词等级、历史记录、每日任务列表，可跨日复用与恢复。
- **CSV 词库导入**：示例词库位于 `data/words.csv`，支持多行中文释义。
- **等级体系（-2..5）**：
	- 等级范围从 -2 到 5，且等级 > 4 视为已掌握。
	- 初始等级为 -2（未认识的新词）。
	- -2 表示新词；-1/0 用于新词阶段的临时过渡；存档中仅保存等级 ≥ 1 的单词状态。
- **抽取与背诵流程**：
	- 新词：每天从“等级为 -2 的全体单词池”抽取，默认随机（可通过 `random_new_selection` 关闭改为顺序）。
	- 复习：每天从“等级为 1..4 的单词池”（>4 视作已掌握）选择，使用“复习候选选择器”产生初始复习列表（基于等级权重 + 遗忘曲线 + 防饥饿的打分与软采样）。
	- 队列 queue：由“当天新词列表 + 初始复习列表”构成，学习过程中始终从队头取词。
	- 队列分段洗牌：队列变更时进行“按 50 词分段的洗牌”，避免长尾导致复习延迟。
- **相似度干扰选项**：基于 `rapidfuzz` 拟合拼写相近单词生成干扰释义。
- **导出报告**：随时将当前掌握情况导出为 CSV。
- **再背一些**：完成一轮后可立即追加少量新词/复习词，数量按配置中 `extra_batch_ratio` 占每日上限的比例自动计算。

## 快速开始

```bash
cd word_cli_demo
python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
word-cli
```

> Windows 环境将 `source .venv/bin/activate` 替换为 `.venv\Scripts\activate`。

运行后首先进入主菜单，可选择：

1. **开始**：进入每日任务界面。
2. **修改配置**：逐项输入新值（回车跳过保持原值）。
3. **导出进度**：将当前掌握情况写入配置中的导出路径。
4. **退出**。

## 背诵界面交互说明

- 新词界面展示英文与中文释义，按 `1/2/3` 选择 **认识/不认识/模糊**，对应将等级设置为 `0/-2/-1`，三种情况都会将该词加入队列（视作待复习）。
- 复习界面仅展示英文，按 `1~4` 选择四个释义中的正确答案，`5` 为 **不认识**（视为答错）；结算页面会用绿色标注正确答案、红色标注错误答案，并在每条释义末尾右对齐展示对应单词。
- 复习判定：
	- 正确：等级 `+1`；若升级后等级 `>= 1`，则认为该词今日背诵完成，从队列移除；否则仍可进入后续队列。
	- 错误：等级 `-1`，并将该词再次加入队列；每日最多只会被降级一次。
- 结算页面提供 `[Backspace] undo · [Enter] next · [Ctrl+C] / [Ctrl+D] exit` 提示；错误或“不认识”必须按 Enter 手动继续，其余情况可通过配置的 `settlement_auto_advance_ms` 设置自动跳转。
- 等级进度以右对齐的 `+` （正数）或 `-` （负数）显示，如 `[   ++]`。
- 撤销仅能在结算页面触发（`Backspace` 或 `Ctrl+Z`），可恢复等级、历史与队列顺序。
- `Ctrl+C` / `Ctrl+D` 可随时退出，当日进度自动保存。
- 每轮任务完成后会弹出 `[1] 结束 / [2] 再背一些` 选项，选择后者将依据配置追加少量新词和复习词继续练习。
- 当日完成度以复习阶段答对为准，新词需要通过随后的复习题目才计入进度。

## 配置与数据文件

- `data/config.json`：默认配置，包含每日上限、相似度候选数、额外批次比例、`settlement_auto_advance_ms`（结算自动跳转毫秒，-1 表示手动）、`words_file`（词库 CSV 路径）、`random_new_selection`（是否随机抽取新词，否则按顺序选取）等。可通过菜单更新，或手动编辑后重新运行。
- `data/progress.json`：存档文件，包含所有单词的等级与历史记录、每日抽取列表。
- `data/words.csv`：示例词库，可替换为自定义 CSV（首列英文，第二列及之后为中文释义）。
- `data/export.csv`：导出文件默认位置，可通过配置修改。

## 复习候选选择器

每日“初始复习列表”的抽取基于一个可解释的评分模型与软采样算法，目标是：
- 更优先复习低等级（不熟练）的单词；
- 根据遗忘曲线在“到期”附近连续而平滑地提权，避免离散日期带来的断档；
- 防止“饥饿”现象（某些词长期不被抽中）。

候选范围：所有等级在 1..4 的单词（等级 >4 视作已掌握，不进入候选）。

记号：
- l：单词等级（1..4）；
- d：距上次复习的天数（缺失或解析失败视作很久未见，优先召回）；
- s_l：该等级的目标复习间隔（天）。

默认超参数（函数内部配置的参数）：
- 目标间隔 target_intervals：{1:1, 2:2, 3:4, 4:7}
- 等级权重 level_weights：{1:1.0, 2:0.7, 3:0.45, 4:0.25}
- Sigmoid 平滑宽度 tau：1.0
- 混合系数 alpha：0.7（在 Sigmoid 与饱和函数间折中）
- 抗饥饿增益权重 beta：0.2（g_age = log(1 + d)）
- bonus_i 权重 gamma：0.0（预留；当前未进行持久化积分）
- softmax 温度 temperature：1.0
- top_k_factor：5（先取前 limit*5 再进行软采样）
- 最小间隔 min_gap_days：{1:1, 2:1, 3:2, 4:3}（过近则强烈降权，避免刚复习又被抽到）

评分模型：
1) 等级权重 w_level(l)：低等级更高。
2) “到期”因子 f_mix：
   - Sigmoid：f_sig = 1 / (1 + exp(-(d - s_l)/tau))
   - 饱和：f_sat = d / (s_l + d)
   - 混合：f_mix = alpha · f_sig + (1 - alpha) · f_sat
   - 若 d < min_gap_days[l]，对 f_mix 施加强降权（乘以 0.05）。
3) 抗饥饿增益：g_age = log(1 + d)。可选的 bonus_i（未启用）用于为长期未被选中的词累积积分。

最终分数：

	score = w_level(l) * f_mix + beta * g_age + gamma * bonus_i

选择流程：
1) 计算所有候选的 score，按分数降序取前 top_k = min(len(pool), limit * top_k_factor)。
2) 对这 top_k 使用 softmax(score/temperature) 进行“无放回采样”，直到抽满 limit 个或池耗尽；若全部分数不为正，则回退为在 top_k 内随机抽取。
3) 抽取后与新词列表合并形成当天队列，并进行“按 50 词分段的洗牌”。

这样既保证了“低等级、到期优先”，又通过软采样与老化增益避免饥饿。
